# Experimentos controlados

Compare black/red/green/blue: uma componente muda por vez. Compare red/wide/tall: apenas uma dimensão muda, repetindo a mesma cor. Compare labels e rect para inferir o percurso dos pixels. O gerador consulta diretamente o formato: use como oráculo antes de ler seu código. Registre a saída antes de formular a próxima consulta. Os casos fresh ficam na suíte de validação, separados destes exemplos iniciais.
